# seoak_backend_initial_setup
GET/student -return all student data.
GET/Student/:id - return a single student by their id.
POST/ student - add a new student (id should Auto - increment).
PUT/student/:id - update the full student record by id.
PATCH/student/:id/grade - update only the grade of a student by id.
DELETE/student/:id - delete a student from the dataset by id.
GET/student/course/: course name - return all students enrolled in specific course.
GET/student/grade/A - return all students who got grade.
